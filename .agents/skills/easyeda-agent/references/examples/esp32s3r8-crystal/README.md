# 晶振负载电容摆位：夹在芯片与晶振之间

ESP32-S3R8 裸片最小系统（#43）PCB 布局中，40 MHz 晶振和两颗负载电容的一次反例与用户修正。
迁移的是相对关系，不是坐标；换芯片或换晶振封装时先读真实焊盘再套用。

## 来源

- 块 `block.esp32s3r8_chip_minsys`：U1（QFN-56）XTAL_P = pin54、XTAL_N = pin53，位于芯片顶边左侧；
  X1 `xtal.40mhz_3225_12pf`（四角焊盘：1 = XTAL_P、3 = XTAL_N 对角，2/4 = GND）；
  C7 = C_X1（XTAL_P）、C8 = C_X2（XTAL_N），12 pF 0402。
- 规则：[布局规范 §7.1](../../pcb-layout-conventions.md)。

## 开始状态

两层板，U1 中心 (0,0)、0°，mil、y 向上、footprint-anchor。U1 pin54 (-71,134)、pin53 (-55,134)。
晶振区上方是 1×4 排针，左侧是 VDDA 去耦 C5 与天线 π 匹配，右侧是 CPU 去耦 C2。

## 反例：负载电容在晶振外侧

`pcb layout-plan` 的 pin-satellites 模块以 X1 为锚，`pinAssignments` 把 C7/C8 的 owner 写成 X1.1 / X1.3，
side 写 left / right。求解结果合法（0 重叠、0 越界），但电容落在晶振左右外侧：

| 件 | 位置 | 角度 |
|---|---|---|
| X1 | (-20, 315) | 0 |
| C7 | (-159, 281) | 180 |
| C8 | (110, 348) | 0 |

XTAL 走线要从芯片脚先到晶振、再绕到外侧电容，电容不在信号路径上。布局 lint、`pcb check` 都没有
相关判据，两轮自检通过后仍是这个形态——这一项目前只能靠规则阅读与图面复核发现。

## 用户修正（现场调整后回读固化）

| 件 | 位置 | 角度 | 关系 |
|---|---|---|---|
| X1 | (-40, 370) | 0 | 上移，给电容让出芯片与晶振之间的一排 |
| C7 | (-80, 265) | 180 | 信号焊盘 C7.1 (-64,265) 朝中线，GND 朝外 |
| C8 | (5, 265) | 0 | 信号焊盘 C8.1 (-12,265) 朝中线，GND 朝外 |

两颗电容同一水平线并排，夹在 U1 振荡脚与晶振之间；XTAL_P/N 从芯片脚出来先经电容焊盘再进晶振，
GND 焊盘在外侧就近接地。

## 实测（save → doc reload → fresh dump）

| 量 | 值 | §7.1 判据 |
|---|---|---|
| X1 中心到 pin54 / pin53 | 238 / 236 mil | ≤ 300 理想 |
| 电容信号焊盘到晶振焊盘 | C7→X1.1 74、C8→X1.3 139 mil | 150–200 内 |
| 芯片脚 → 电容 → 晶振 全程 | P 205、N 277 mil | 两腿差 72 mil：对角焊盘封装的固有差 |
| 守护环 200 mil 内其他件 | C2 / C5 10、U1 95、J1 82、C4 155、C11 158 | 密板未满足，用户确认接受 |
| 晶振到板边 | 121 mil | advisory ≥ 394 未满足，用户确认接受 |

layout-lint 0 重叠 / 0 越界，`pcb check` 0 ERROR。

## 做法

1. 在 layout 源数据里把负载电容的 owner 写成 MCU 振荡脚（不是晶振焊盘），side 朝晶振；或直接
   手定坐标：电容信号焊盘落在「芯片脚 → 晶振焊盘」连线上，GND 焊盘朝外。
2. 晶振整体远离芯片一点，给电容让出一排；体中心距振荡脚仍 ≤ 300 mil。
3. 对角焊盘晶振的两腿差约一个焊盘间距，按电容相对晶振中线的对称判，不要为凑 50 mil 把电容拉离路径。
4. 守护环与板边距离在密板上常冲突，逐项列出实测值交用户取舍，不能用 lint 通过代替。

## 包地净空（2026-10-17 现场）

来源：考试说明 p5「晶振…避免底层走线，顶层做包地净空处理」，用户要求「包地打孔一圈 GND 并禁止顶层铺铜」。

| 项 | 参数（mil） |
|---|---|
| 包地线 | 顶层 GND 10 mil，矩形 (-150,238)–(65,450)；底边芯片侧缺口 x -106..21.5 给 XTAL_P/N 进线，两端 45° 收进 C7.2 / C8.2 焊盘 |
| GND 焊盘接环 | C7.2、C8.2、X1.2、X1.4 各一段短桩接包地线 |
| 过孔围栏 | 左/上/右三边 11 个 24/12 过孔；底边夹在 C5/C2 与 C7/C8 之间仅 33 mil，`via-fence` 预检拒绝，只走线 |
| 净空 | 顶层环内 `no-pours`；晶振下方底层 `no-wires`，底层 GND 铺铜完整 |
| 晶振走线 | XTAL_P/N 8 mil 全顶层、无过孔，芯片脚 → 负载电容焊盘 → 晶振 |

全部锁定后再交官方路由器；保存重载后 DRC `passed:true`，`pcb check` 0 ERROR、0 断头、0 锐角。
