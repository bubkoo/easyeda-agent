# PCB 参数化外壳：设计

目标：基于已有 PCB 的回读数据，生成可直接 3D 打印的外壳（上下壳或推盖盒，STL/STEP），
包括挖槽、螺丝柱、卡扣和凸出实体。EDA 内置外壳不开放创建接口（见 [PCB 3D 建模设计](pcb-3d-design.md)），
所以外壳几何由我们离线计算，不写回 EDA。字段、算法与测试见 [详细稿](pcb-enclosure-design-detail.md)。

## 使用方式

```sh
easyeda pcb dump --project <p> --out board.json            # 板框、器件位置与包围盒
easyeda pcb 3d models --project <p> > models.json           # 器件模型名与高度
easyeda pcb enclosure plan --board board.json --models models.json --top-cutout SW1 --height J1=8.5 --out spec.json
#   → 可编辑的外壳参数：尺寸、上下壳分割、螺丝柱、挖槽、实体，每项注明来源
easyeda pcb enclosure build --spec spec.json --out ./enclosure
#   → bottom.stl、top.stl、preview.png、manifest.json；加 --step 另出 STEP
easyeda pcb enclosure plan --board board.json --type slide --pillar 3,3,M2 --out spec.json   # 推盖盒 + 手加螺丝柱
```

`plan` 只给出起点：高度不明的器件用 `--height` 补上后重新 `plan`（总高随之重算），没有安装孔时
用 `--pillar X,Y[,M3]` 加螺丝柱；其余挖槽和实体可直接改 `spec.json` 再 `build`。两步都离线运行，不访问 EDA。

## 核心方案

- **外形**：默认沿板框外扩 `clearance` 再加壁厚；也可选矩形。
- **两种类型**：上下壳（`split`，默认）在板面高度处分开，下壳内侧有止口，上壳有对应凹槽；
  推盖盒（`slide`，仅矩形）四壁顶部下方开导槽，盖板从 `--slide-side` 一侧滑入。
- **卡扣**：上下壳没有螺丝柱时，`plan` 在四边中点各放一个卡扣：下壳止口外侧凸点，上壳对应位置开窗。
- **高度**：用器件高度（模型名里的 `H1.3`、`Height` 属性，没有时用默认值并标出），
  算出板上最高器件，再加净空和顶板厚度。
- **挖槽和实体用同一种元素**：一个平面形状（矩形或圆，可旋转）加一段 Z 范围，
  `cut` 表示挖掉，`add` 表示加上，并指定作用于上壳、下壳或两者。顶/底开孔、侧面开口、
  凸台都用它表达。
- **螺丝柱**：M2–M6 查表展开为柱体和孔。上下壳：螺丝从底部穿过下壳和 PCB，拧进上壳的柱子；
  推盖盒：螺丝从上穿过 PCB 拧进下壳柱子。
- **自动推导**（`plan`）：板边附近的连接器（J/CN/USB 等）自动生成侧面开口；
  命名像安装孔的器件生成螺丝柱；按键、LED 只列为候选，用 `--top-cutout` 明确指定后才开孔。
- **几何算法**：XY 平面按固定分辨率（默认 0.1 mm）栅格化，Z 方向只在特征高度分层，
  逐格做布尔运算后输出闭合流形网格。轴向平面是精确的，曲线是 0.1 mm 台阶，满足打印精度。
  不引入新依赖。

## 检查（`build` 自动执行）

- 每个器件的立体包围盒（XY 包围盒 × 板面到器件顶）与外壳实体不得相交；
  伸出板外的连接器必须被开口让开。PCB 板体与外壳也不得相交。
- 两件不得重叠；每个卡扣必须真的在止口上形成凸点和窗口；推盖必须能沿滑出方向抽出而不碰盒体。
- 网格须是闭合流形且体积与栅格一致，否则判失败。
- 警告：壁厚、顶底厚度小于 1.5 mm；任何方向上比 0.8 mm 还细的实体（如两个开孔之间的细条）。
- 每次都输出 `preview.png`（两件并排，第二件翻转显示内侧），失败时也输出，便于定位。
- 失败时仍保留 `manifest.json` 说明原因，不输出可能有问题的 STL。

## 本期范围

- 包含：上下壳与止口、推盖盒、卡扣、顶/底/侧面挖槽、凸出实体、螺丝柱、沿板框或矩形外形、
  干涉与可打印性检查、预览图、STL 与 STEP 输出。
- 不包含：写回 EDA 的外壳层（官方无接口）。
- 状态（2026-10-23）：已实现。离线单测覆盖推导、布尔、螺丝柱、卡扣、推盖滑出、干涉、网格与 STEP
  引用完整性；ceshi 真板回读分别生成上下壳与推盖盒，检查全过，四件 STL 经独立脚本核对为闭合流形、
  体积一致。STEP 未经 CAD 软件导入验证；尚未实际打印。

## 实施顺序

1. `pkg/enclosure`：参数结构、栅格布尔、网格与 STL 输出，离线单测。
2. `pcb enclosure build`：读参数、检查、出 STL 与清单。
3. `pcb enclosure plan`：由板子回读推导参数。
4. 用 ceshi 真板回读跑通，并用独立脚本核对 STL；在切片软件中打开和实际打印由用户完成。
