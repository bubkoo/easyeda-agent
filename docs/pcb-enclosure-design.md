# PCB 参数化外壳：设计

目标：基于已有 PCB 的回读数据，生成可直接 3D 打印的上下壳（STL），包括挖槽、螺丝柱和
凸出实体。EDA 内置外壳不开放创建接口（见 [PCB 3D 建模设计](pcb-3d-design.md)），
所以外壳几何由我们离线计算，不写回 EDA。字段、算法与测试见 [详细稿](pcb-enclosure-design-detail.md)。

## 使用方式

```sh
easyeda pcb dump --project <p> --out board.json            # 板框、器件位置与包围盒
easyeda pcb 3d models --project <p> > models.json           # 器件模型名与高度
easyeda pcb enclosure plan --board board.json --models models.json --top-cutout SW1 --height J1=8.5 --out spec.json
#   → 可编辑的外壳参数：尺寸、上下壳分割、螺丝柱、挖槽、实体，每项注明来源
easyeda pcb enclosure build --spec spec.json --out ./enclosure
#   → bottom.stl、top.stl、manifest.json（尺寸、体积、干涉检查结果、哈希）
```

`plan` 只给出起点：高度不明的器件用 `--height` 补上后重新 `plan`（总高随之重算），螺丝柱、
挖槽和实体可直接改 `spec.json` 再 `build`。两步都离线运行，不访问 EDA。

## 核心方案

- **外形**：默认沿板框外扩 `clearance` 再加壁厚；也可选矩形。上下壳在板面高度处分开，
  下壳内侧有止口，上壳有对应凹槽。
- **高度**：用器件高度（模型名里的 `H1.3`、`Height` 属性，没有时用默认值并标出），
  算出板上最高器件，再加净空和顶板厚度。
- **挖槽和实体用同一种元素**：一个平面形状（矩形或圆，可旋转）加一段 Z 范围，
  `cut` 表示挖掉，`add` 表示加上，并指定作用于上壳、下壳或两者。顶/底开孔、侧面开口、
  凸台都用它表达。
- **螺丝柱**：M2–M6 查表展开为柱体和孔。螺丝从底部穿过下壳和 PCB，拧进上壳的柱子。
- **自动推导**（`plan`）：板边附近的连接器（J/CN/USB 等）自动生成侧面开口；
  命名像安装孔的器件生成螺丝柱；按键、LED 只列为候选，用 `--top-cutout` 明确指定后才开孔。
- **几何算法**：XY 平面按固定分辨率（默认 0.1 mm）栅格化，Z 方向只在特征高度分层，
  逐格做布尔运算后输出闭合流形网格。轴向平面是精确的，曲线是 0.1 mm 台阶，满足打印精度。
  不引入新依赖。

## 检查（`build` 自动执行）

- 每个器件的立体包围盒（XY 包围盒 × 板面到器件顶）与外壳实体不得相交；
  伸出板外的连接器必须被开口让开。PCB 板体与外壳也不得相交。
- 壁厚、顶底厚度小于 1.5 mm 时给警告；网格须是闭合流形且体积与栅格一致，否则判失败。
- 不检查细小隔条：两个开孔靠得太近会留下难以打印的细条，需人工看预览或调整参数。
- 失败时仍保留 `manifest.json` 说明原因，不输出可能有问题的 STL。

## 本期范围

- 包含：上下壳、止口、顶/底/侧面挖槽、凸出实体、螺丝柱、沿板框或矩形外形、干涉检查。
- 不包含：推盖式外壳、卡扣、STEP 输出、渲染预览、写回 EDA 的外壳层。
- 状态（2026-10-23）：已实现。离线单测覆盖推导、布尔、螺丝柱、干涉和网格；ceshi 真板回读
  `plan → build` 通过，两件 STL 经独立脚本核对为闭合流形、体积一致。尚未实际打印。

## 实施顺序

1. `pkg/enclosure`：参数结构、栅格布尔、网格与 STL 输出，离线单测。
2. `pcb enclosure build`：读参数、检查、出 STL 与清单。
3. `pcb enclosure plan`：由板子回读推导参数。
4. 用 ceshi 真板回读跑通，并用独立脚本核对 STL；在切片软件中打开和实际打印由用户完成。
